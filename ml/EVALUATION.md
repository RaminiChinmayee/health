**Symptom checker ranking (v1.1.0):** plain Naive Bayes treated every unticked symptom as absent, so one symptom (e.g. high fever) favoured diseases with few symptoms such as HIV/AIDS. The app now treats unticked symptoms as "not mentioned" (penalty grows with the number selected), counts a typical symptom equally for every disease that has it, and applies a "common in India" weighting (a clinical-knowledge heuristic, not measured prevalence). Correct disease in the top 5: 1 symptom 63% → 79%, 2 symptoms 88% → 98%; with 50% of symptoms top-1 is 95% (was 98%; the evenly balanced test data can only penalise the prior). Details in `artifacts/symptoms/1.1.0/report.md`.

**Kidney and lung models (added 2026-11-21):** the kidney model (UCI Chronic Kidney Disease, Apollo Hospitals, Tamil Nadu) separates CKD patients from largely healthy controls, so its very high scores are optimistic for borderline cases; optional lab inputs were removed because blank fields were filled with CKD-heavy typical values and inflated healthy users' estimates (35-year-old with normal values: 43% → 5.5%). The lung model uses a small, weakly documented survey (87% with lung cancer, licence CC BY-NC-SA 4.0); it is class-balanced and shown as "resembles group", not a risk, and its test set contains very few people without cancer, so its specificity is highly uncertain. Some associations in that survey (e.g. allergy, alcohol) look like data artefacts.

**Reading these numbers:** they describe performance on each source dataset's population (see each report). They are not clinical validation, and none of these models diagnoses disease. The symptom checker's scores measure agreement with a synthetic disease–symptom table, not diagnostic accuracy in real patients.

## Phase 5: skin-lesion image model

Full report: [artifacts/skin/1.0.0/report.md](artifacts/skin/1.0.0/report.md) (all numbers generated by `ml/train_skin.py`).

- **Data:** HAM10000, 10,015 dermatoscopic images (CC BY-NC 4.0). Split grouped by lesion so no lesion appears in more than one split: 7153 train / 1431 validation / 1431 test.
- **Model:** EfficientNet-B0, ImageNet-pretrained, fine-tuned for 5 epochs on CPU; temperature scaling (T = 0.73); flip test-time augmentation.
- **Test results (1431 images):** accuracy 81.6% (majority-class baseline 66.9%), balanced accuracy 64.7%, macro-F1 0.659, macro ROC-AUC 0.940. Calibration error (ECE) 0.088 → 0.043 after temperature scaling.
- **Per class:** melanoma sensitivity 59.1% (specificity 94.4%); basal cell carcinoma 79.7%; moles 90.7%; actinic keratosis only 32.6%, the weakest class.
- **Non-skin rejection:** a distance check rejects 0.6% of real test images and all 30 synthetic non-skin images; a Gemini vision check runs as well. Not yet evaluated on realistic everyday non-skin photos.
- **Limitations:** dermatoscope images of mostly lighter skin from Austria and Australia; only 7 lesion types; not a diagnosis.
